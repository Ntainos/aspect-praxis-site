# Praxis · site · τελικό σχέδιο (γύρος 6, με τις αλλαγές του ιδιοκτήτη)

Εμφάνιση και κείμενα του aspect-praxis.com. Σχέδιο που συμφώνησαν 3 κριτές σε 5 γύρους (όλοι ≥9, κανένα σοβαρό),
και ο γύρος 6 με τις αλλαγές του ιδιοκτήτη (τεχνητή νοημοσύνη στο προσκήνιο, χωρίς «πιλοτική φάση», «ήδη υπό ανάπτυξη»).
Κρίσεις γύρου 6: σχεδιαστής ταυτότητας 9,5 · σαφήνεια και κινητό 9,25 · δύσπιστος συμβολαιογράφος 8,75 με 1 σοβαρό, που διορθώθηκε
στο τελικό («Γράφει όπως ένα συμβολαιογραφικό γραφείο»).

**Για τον Codex:** οι εικόνες είναι η αναφορά. Δεν υπάρχει κώδικας· το site χτίζεται από την αρχή ώστε να μοιάζει με τις εικόνες.

| Φάκελος / αρχείο | Τι είναι |
|---|---|
| `eikones/<σελίδα>__1440.png` | κάθε σελίδα σε υπολογιστή (ολόκληρη) |
| `eikones/<σελίδα>__390.png` | η ίδια σελίδα σε κινητό |
| `eikones/odigos__*.png` | οδηγός εμφάνισης: logo, χρώματα, γραμματοσειρά (Geologica), αποστάσεις, γωνίες, σκιές, εικονίδια, κουμπιά, φόρμες, καταστάσεις, κανόνες |
| `keimena.md` | όλα τα κείμενα, σελίδα-σελίδα, αυτούσια |
| `logo/` | το logo του Praxis σε SVG |
| `deltio_gegonoton.md` | τι επιτρέπεται να λέει το site· ό,τι δεν είναι εκεί δεν γράφεται |
| `brief.md` | οι αποφάσεις του ιδιοκτήτη (και του γύρου 6) |
| `kritikes/` | οι κρίσεις και οι αλλαγές του γύρου 6 |
| `aporrifthikan/` | οι 2 εκδοχές του γύρου 1 που δεν προχώρησαν |

Σελίδες: `index` (Αρχική) · `pos-leitourgei` (Πώς λειτουργεί) · `eidi` (Είδη πράξεων) · `dedomena` (Ασφάλεια και δεδομένα) · `times` (Τιμές) · `aitisi` (Αίτηση).
Οι εικόνες της εφαρμογής μέσα στο site είναι **σχηματικές** (πλασματικά στοιχεία)· αργότερα αντικαθίστανται από πραγματικά στιγμιότυπα.
Ό,τι γράφει `[●]` συμπληρώνεται αργότερα (τιμές, στοιχεία εταιρείας).
