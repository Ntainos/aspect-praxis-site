## Βήμα 1 · Βάση

Υλοποιήθηκε μόνο η στατική βάση Astro και η εσωτερική `/odigos`: κοινό layout, sticky μπάρα, προσβάσιμο mobile menu, footer, κουμπιά/κάρτες, μεταβλητές CSS και τοπική Geologica με OFL. Ενσωματώθηκαν τα εγκεκριμένα Aspect SVG και ο τέταρτος νομικός σύνδεσμος από το ενημερωμένο main.

### Τοπική εκτέλεση

`npm ci`, `npm run dev` και διαδρομή `/odigos`. Για έλεγχο παραγωγικής εξόδου: `npm run build`, `npm run preview -- --host 127.0.0.1`, σε άλλο terminal `npm test` (απαιτεί Chromium· `/usr/bin/chromium` ή `CHROMIUM_PATH`).

### Έλεγχοι

- Static build: επιτυχία, μόνο μία σελίδα.
- Chromium στα 1440/768/390: χωρίς οριζόντια κύλιση, sticky header, μενού με κλικ/αφή/Enter/Space/Tab/Escape, τοπική γραμματοσειρά, noindex, unchecked Όροι, κανένα API ή αποθήκευση.
- Μηδενικές εξωτερικές αιτήσεις στη φόρτωση και χρήση μενού.
- axe WCAG A/AA: 0 παραβιάσεις και στα τρία πλάτη.
- Lighthouse Accessibility 100, Best Practices 100.
- Το design/ παρέμεινε αμετάβλητο έναντι main και δεν περιλαμβάνεται στο dist/.

Η /odigos είναι επιτρεπόμενο υποσύνολο του πλήρους φύλλου, όχι pixel-perfect ανακατασκευή όλων των διαγραμμάτων. Διαφέρουν συνολικό ύψος, διάταξη δειγμάτων κουμπιών/πεδίων και κάθετες θέσεις. Χρησιμοποιείται το νέο επίσημο κατακόρυφο Aspect logo αυτούσιο, αντί για την οριζόντια σύνθεση των εικόνων. Ο τέταρτος νομικός σύνδεσμος προστίθεται βάσει έγκρισης. Οι στόχοι footer είναι 44 px και οι σύνδεσμοι μέσα σε κείμενο υπογραμμίζονται για προσβασιμότητα.

### Διόρθωση Βήματος 1 · μπάρα και μενού

Διορθώθηκαν η desktop στοίχιση (πλοήγηση x=532 στα 1440 px), η διαχωριστική γραμμή Praxis/Aspect και τα mobile κουμπιά (x=185/274 στα 390 px). Προστέθηκαν τα απλά SVG μενού/κλεισίματος και βελών. Το ανοιχτό μενού απέκτησε τις προβλεπόμενες καταστάσεις hover/focus, κύριο πετρόλ Button 52 px και διαχωρισμένη αναφορά με το επίσημο σύμβολο Aspect. Διατηρήθηκαν πληκτρολόγιο, Escape, εστίαση και ARIA.

Ανανεώθηκαν όλα τα screenshots και οι συγκρίσεις μπάρας, πλέον με αναφορά στις εικόνες index. Επαναλήφθηκαν build/tests στα 1440/768/390, axe και με ανοιχτό μενού, στόχοι ≥44 px και μηδενικές εξωτερικές αιτήσεις. Το Lighthouse επανελέγχθηκε (100/100). Η αναφορά εξηγεί τις μικρές εναπομείνασες διαφορές της λέξης Praxis/επίσημης αναφοράς Aspect και τη διαφορά εξωτερικού πλάτους από τη μικρογραφία του ανοιχτού μενού στον οδηγό.

Καμία αλλαγή στο design/, σε άσχετα components ή στην αρχιτεκτονική. Εργασία μόνο στο υπάρχον `feat/step-1-foundation`, χωρίς νέο branch ή merge. Το άνοιγμα PR παραμένει χειροκίνητο από τον ιδιοκτήτη λόγω του ήδη διαπιστωμένου περιορισμού GitHub API.
