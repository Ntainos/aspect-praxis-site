- Η Αρχική αποκτά τον εγκεκριμένο τίτλο ταυτότητας/τεχνητής νοημοσύνης αντί του παλιού τίτλου hero. Η description γίνεται η πρώτη πλήρης πρόταση εισαγωγής, ακριβώς όπως δόθηκε.

- Οι περιγραφές Πώς λειτουργεί, Τιμές και Αίτηση παραμένουν οι αρχικές εγκεκριμένες αυτούσιες επιλογές.

Το κοινό Layout δέχεται προαιρετικό description prop και αποδίδει ένα meta description μόνο όταν παρέχεται. Οι έξι σελίδες παρέχουν ακριβώς τα εγκεκριμένα props. ## Εκκρεμότητες και προστασία

Το [BLOCKERS.md](BLOCKERS.md) συμπληρώθηκε με εταιρικά/ΓΕΜΗ/νομική μορφή, κάλυψη δημόσιου site/Cloudflare/IP/αιτήσεων από την Πολιτική απορρήτου, νομική βάση/διατήρηση και πραγματική διαγραφή, cookies, νομική κρίση για τους Όρους κατά την αίτηση, συμβάσεις πραγματικού παρόχου AI και μη εκπαίδευση, παραγωγική επαλήθευση «λειτουργούν ήδη» και δοκιμή επαναφοράς backup. Προαιρετική μελλοντική αντικατάσταση σχηματικών εικόνων μόνο με εγκεκριμένα δοκιμαστικά δεδομένα.

Το checkbox, API και νομικοί προορισμοί δεν αλλάζουν. Δεν προστίθεται λογότυπο Cloudflare· η νομική αναφορά στη φιλοξενία ανήκει στην Πολιτική απορρήτου της εφαρμογής και στον νομικό έλεγχο.

Το `public/_headers` και το γενικό `X-Robots-Tag: noindex, nofollow` παραμένουν ακριβώς ίδια. Δεν προστέθηκαν canonical, sitemap, robots.txt, Open Graph, JSON-LD, verification, analytics ή cookie banner. Δεν ενεργοποιείται index μέσω άλλης δήλωσης. Αυτά ανήκουν σε ξεχωριστή τελική εργασία, μόνο μετά από ρητή έγκριση δημόσιας λειτουργίας.

Το main και το cf-placeholder παραμένουν ανέπαφα. Δεν έγινε merge, deployment, αλλαγή production branch, DNS, Cloudflare ή Access. Η αναφορά του ιδιοκτήτη ότι η πρόσβαση προστατεύεται από Cloudflare Access δεν ελέγχθηκε από εμάς. Η παράδοση προορίζεται αποκλειστικά για **Draft PR**, χωρίς συγχώνευση.
