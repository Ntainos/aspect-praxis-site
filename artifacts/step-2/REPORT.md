# Βήμα 2 · Αρχική

## Πεδίο

Βάση: ενημερωμένο `main`, merge commit `12c972e` του PR #1. Branch: `feat/step-2-homepage`.

Υλοποιήθηκε μόνο η `/`: hero, δύο κάρτες δυνατοτήτων, τρία βήματα, 23 είδη πράξεων, ασφάλεια/διάγραμμα, τιμές και κοινό κλείσιμο αίτησης. Η μπάρα, το footer, το layout, τα Button/Card και οι μεταβλητές του Βήματος 1 επαναχρησιμοποιούνται χωρίς τροποποίηση. Το `ApplicationClosing.astro` φορτώνει το δικό του stylesheet ώστε να μπορεί να χρησιμοποιηθεί και στις μελλοντικές σελίδες.

Οι απεικονίσεις είναι στατικό HTML/CSS/inline SVG σε χωριστά components (`ProductIllustration`, `DataDiagram`). Δεν υπάρχουν πεδία ή κουμπιά που υποδύονται λειτουργική εφαρμογή, ούτε νέα JavaScript. Οι οπτικές ενδείξεις έγκρισης/απόρριψης είναι απλά κείμενα, χωρίς εστίαση ή handlers. Τα διακοσμητικά SVG αποκρύπτονται από αναγνώστες οθόνης. Τα κείμενα δυνατοτήτων/ασφάλειας και η σειρά των 23 ειδών προέρχονται αυτούσια από το `keimena.md`, αποθηκευμένα στο `src/data/home.json`.

## Εκτέλεση

```sh
npm ci
npm run dev
```

Για έλεγχο της στατικής εξόδου:

```sh
npm run build
npm run preview -- --host 127.0.0.1
```

Με ενεργό preview στη θύρα 4321, σε άλλο terminal:

```sh
npm run test:home
npm test
CHROME_PATH=/usr/bin/chromium npx lighthouse http://127.0.0.1:4321/ --only-categories=accessibility,best-practices --chrome-flags='--headless --no-sandbox' --output=json --output-path=artifacts/step-2/lighthouse.json --quiet
```

Οι browser tests απαιτούν τοπικό Chromium (`/usr/bin/chromium` ή `CHROMIUM_PATH`). Το `test:home` δημιουργεί και τα screenshots/συγκρίσεις. Στις συγκρίσεις το design βρίσκεται αριστερά και η υλοποίηση δεξιά, στην ίδια ακριβώς κλίμακα. Ο λευκός χώρος κάτω από τη συντομότερη εικόνα διατηρεί αυτή την κλίμακα, χωρίς τέντωμα.

## Επαληθευμένα αποτελέσματα

- Static build: επιτυχία, ακριβώς δύο σελίδες (`/`, `/odigos`).
- Browser tests: επιτυχία στα **1440, 768, 390 px**. Ένας H1 με το ακριβές εγκεκριμένο κείμενο, `lang="el"`, χωρίς οριζόντια κύλιση και χωρίς JavaScript errors.
- Desktop/tablet: **23 είδη** στην εγκεκριμένη σειρά και **6 σημεία ασφάλειας**. Mobile: τα πρώτα **8 είδη** και τα σημεία **1, 2, 6** της ασφάλειας, όπως στην εικόνα.
- Mobile: κρυφή δεύτερη ετικέτα hero, απλοποιημένη εικόνα χωρίς sidebar/βοηθό συνομιλίας, κρυφές περιγραφές δυνατοτήτων, κάθετα βήματα χωρίς μικρογραφίες, κρυφή κάρτα τιμών, κάθετη ροή δεδομένων.
- Έλεγχος αντιστοίχισης κειμένων με την εγκεκριμένη πηγή, όλων των 23 ονομασιών/αριθμών, ποσού `[●] € / μήνα` και των links της Αρχικής. Δεν προστέθηκαν ποσά ή ονόματα πακέτων. Οι ενδείξεις `[●]` παραμένουν αυτούσιες.
- Όλα τα links του main δείχνουν αποκλειστικά σε `/aitisi`, `/pos-leitourgei`, `/eidi`, `/dedomena`, `/times` ή στο εγκεκριμένο email.
- Sticky μπάρα μετά από κύλιση και μενού με Enter, Escape, επιστροφή εστίασης, κλικ/αφή. Οι υφιστάμενοι αναλυτικοί έλεγχοι της `/odigos` πέρασαν ξανά.
- Μηδενικές εξωτερικές αιτήσεις, cookies, localStorage και sessionStorage. Η Geologica και τα SVG φορτώθηκαν από την τοπική προέλευση. Δεν υπάρχει API, υποβολή αίτησης ή νέα λειτουργική JavaScript.
- axe WCAG 2/2.1 A/AA: **0 παραβιάσεις** στα τρία πλάτη. Lighthouse Αρχικής: **Accessibility 100, Best Practices 100**. Τα αποτελέσματα βρίσκονται στα `results.json` και `lighthouse.json`. Οι αυτοματοποιημένοι έλεγχοι δεν αποτελούν πλήρη πιστοποίηση WCAG.
- `design/`, κοινή μπάρα, footer, κοινό layout και global CSS: καμία αλλαγή έναντι `main`. Το `dist/` δεν περιέχει design, screenshots ή αναφορές.

## Οπτική επιθεώρηση και αποκλίσεις

Έγιναν διαδοχικές συγκρίσεις της πλήρους σελίδας και επιθεώρηση των ενοτήτων. Μειώθηκαν τα επιπλέον ύψη της συνομιλίας στο hero, οι αποστάσεις των καρτών, τα κενά της λίστας ειδών και η τυπογραφία/κενά των κόμβων δεδομένων. Παραμένουν οι παρακάτω διαφορές· δεν δηλώνεται pixel-perfect ταύτιση:

1. **Hero:** ίδιες ενότητες, κείμενα, διάταξη τίτλου, κουμπιά και προειδοποίηση ευθύνης. Παραμένουν διαφορές στα σπασίματα του εισαγωγικού κειμένου και στις διαστάσεις των στηλών της προσομοίωσης. Το desktop preview έχει διαφορετικό μήκος σχηματικών γραμμών και λίγο διαφορετικό ύψος λευκής σελίδας. Η σκιά είναι η εγκεκριμένη μεταβλητή, αλλά η τελική οπτική έκταση διαφέρει λόγω ύψους. Το μικρό κενό στην προσομοίωση συνομιλίας είναι στατικό, χωρίς λειτουργία.
2. **Κάρτες δυνατοτήτων:** διατηρούνται όλα τα σημεία και οι περιγραφές desktop και μόνο οι τίτλοι mobile. Διαφέρουν ελαφρά τα σπασίματα των τίτλων και τα ύψη γραμμών/καρτών. Τα απλά γραμμικά εικονίδια ανακατασκευάστηκαν ως SVG, χωρίς εξωτερική βιβλιοθήκη.
3. **Τρία βήματα:** η δομή και η σειρά είναι ίδιες. Οι μικρογραφίες του desktop έχουν λιγότερες εσωτερικές λεπτομέρειες και διαφορετικό μήκος σχηματικών γραμμών. Η μικρογραφία Word δεν είναι πραγματικό screenshot. Τα βήματα mobile διατηρούν το εγκεκριμένο κατακόρυφο μοντέλο και τα πλήρη κείμενα.
4. **Είδη πράξεων:** ίδια αρίθμηση και σειρά. Παραμένουν μικρές διαφορές πλάτους στηλών, αναδίπλωσης μεγάλων ονομασιών και ύψους γραμμών. Στο mobile ο σύνδεσμος ακολουθεί τα οκτώ είδη. Στο desktop βρίσκεται κάτω από την εισαγωγή.
5. **Ασφάλεια:** διατηρούνται κόμβοι, όριο ΕΕ, δύο διακριτές αποστολές (αποσπάσματα και μία λέξη), ψευδώνυμα και λεζάντες. Διαφέρουν οι διαστάσεις κόμβων, τα μήκη/ύψη συνδέσεων και ορισμένες αναδιπλώσεις. Στα 390 px η ενότητα παραμένει ψηλότερη από την αναφορά. Τα εικονίδια έχουν αντίστοιχες έννοιες, με μικρές διαφορές διαδρομών SVG.
6. **Τιμές:** η κάρτα desktop και τα `[●]` υπάρχουν, και αποκρύπτονται στο mobile. Διαφέρουν ελαφρά το πλάτος κάρτας, τα εσωτερικά κενά και οι αλλαγές γραμμής στην περιγραφή χρέωσης.
7. **Κοινό κλείσιμο:** ίδιο περιεχόμενο και διάταξη δύο στηλών/μίας στήλης. Παραμένουν διαφορές αναδίπλωσης και τελικού κενού πριν το footer. Το footer διατηρήθηκε όπως εγκρίθηκε στο Βήμα 1: επίσημο κατακόρυφο Aspect logo, τέταρτος νομικός σύνδεσμος και στόχοι αφής ≥44 px, που διαφέρουν από το παλαιότερο screenshot.
8. **Ενδιάμεσο πλάτος:** στα 768 px παραμένουν οι πλήρεις λίστες/περιγραφές και οι μικρογραφίες, με την ήδη εγκεκριμένη μπάρα κινητού. Οι απλοποιήσεις της Αρχικής εφαρμόζονται έως 700 px. Δεν υπάρχει εικόνα αναφοράς 768 px· επιβεβαιώθηκαν η λειτουργία, η προσβασιμότητα και η απουσία οριζόντιας κύλισης.

Για συγκεκριμένο μέτρο της εναπομείνασας κάθετης απόκλισης, η σκοτεινή ενότητα ασφάλειας ξεκινά περίπου στο y=3899 αντί y=3855 στα 1440 px και στο y=4065 αντί y=4009 στα 390 px. Τα πλήρη ύψη/θέσεις της υλοποίησης καταγράφονται ανά ενότητα στο `results.json`. Οι παραπάνω αποκλίσεις είναι ορατές στις συγκρίσεις και παραμένουν για αξιολόγηση.
