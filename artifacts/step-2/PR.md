## Βήμα 2 · Αρχική σελίδα

Υλοποιείται μόνο η `/` πάνω στο ενημερωμένο `main` (`12c972e`, PR #1), με επαναχρησιμοποίηση του layout, της μπάρας, του footer, των Button/Card και των CSS μεταβλητών. Περιλαμβάνονται hero με στατική προσομοίωση εφαρμογής, κάρτες δυνατοτήτων, τρία βήματα, 23 είδη πράξεων, διάγραμμα ασφάλειας, τιμές και επαναχρησιμοποιήσιμο `ApplicationClosing` με δικό του stylesheet. Δεν προστίθεται JavaScript πέρα από το υπάρχον μενού.

### Εκτέλεση και έλεγχοι

`npm ci`, `npm run dev` και διαδρομή `/`. Για στατική έξοδο: `npm run build`, `npm run preview -- --host 127.0.0.1`. Με το preview ενεργό στη θύρα 4321: `npm run test:home` και `npm test` (απαιτούν τοπικό Chromium, `/usr/bin/chromium` ή `CHROMIUM_PATH`).

- Build: επιτυχία, `/` και `/odigos`.
- Browser tests 1440/768/390: σωστός H1, `lang`, links, εγκεκριμένα κείμενα/σειρά ειδών, placeholders, sticky μπάρα και μενού, χωρίς οριζόντια κύλιση ή JS errors.
- Desktop 23 είδη/6 σημεία ασφάλειας· mobile 8 είδη/3 σημεία (1, 2, 6). Επιβεβαιώθηκαν οι προβλεπόμενες mobile αποκρύψεις/απλοποιήσεις.
- Μηδενικές εξωτερικές αιτήσεις και αποθήκευση δεδομένων. Τοπική Geologica και SVG.
- axe WCAG A/AA: 0 παραβιάσεις και στα τρία πλάτη. Lighthouse Accessibility **100**, Best Practices **100**.
- Οι υφιστάμενοι έλεγχοι `/odigos` πέρασαν ξανά. `design/`, μπάρα, footer, layout και global CSS παραμένουν αμετάβλητα. Τα artifacts βρίσκονται εκτός `dist/`.

### Διόρθωση Βήματος 2

Στοχευμένο CSS μόνο στην Αρχική: ουδέτερο περίγραμμα/μελάνι και εγκεκριμένες καταστάσεις στο δευτερεύον κουμπί hero κινητού, διόρθωση συσσωρευμένων κενών προηγούμενων ενοτήτων και συμπαγέστερες αποστάσεις/διάστιχο στους κόμβους ασφάλειας.
